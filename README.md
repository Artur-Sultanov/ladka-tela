# Massage Landing Page

Responsive one-page landing website for a massage cabinet.  
Created as a **learning and portfolio project** to practice modern frontend fundamentals.

🔗 **Live demo:**  
https://artur-sultanov.github.io/massage-landing-page/

---

## 📌 Project Overview

This project represents a presentation website for a massage specialist in Granada.  
The main goal was to build a clean, fast and accessible landing page using **pure web technologies**, without frameworks.

Key focus areas:

- semantic HTML
- responsive layout
- media optimization (images & video)
- clean UX interactions
- GitHub Pages deployment

---

## 🛠 Tech Stack

- **HTML5** — semantic markup
- **CSS3** — responsive layout, modern properties (`aspect-ratio`, `object-fit`)
- **Vanilla JavaScript** — dynamic rendering from JSON, scroll interactions
- **JSON** — content-driven sections (services, gallery, reviews)
- **FFmpeg** — hero video generation & optimization
- **Git & GitHub Pages** — version control and deployment

---

## ✨ Features

- Responsive one-page layout
- Hero section with optimized background video
- Services rendered dynamically from JSON
- Gallery with consistent 4:3 image ratio
- Lightbox for gallery images
- Scrollspy navigation
- Accessibility support (`prefers-reduced-motion`)
- Optimized media assets for fast loading
- Custom favicon and metadata

## 🚀 Deployment

The project is deployed using **GitHub Pages** directly from the `main` branch.

Steps:

1. Push changes to `main`
2. GitHub Pages automatically rebuilds the site
3. Live version available within 1–2 minutes

It demonstrates the ability to:
